# Mapa jugable

`campus-definitivo-v1.png` es la ilustración cenital utilizada como fondo del
escenario de exploración. Su tamaño nativo de 1536 × 1024 píxeles determina las
dimensiones del mundo de Phaser.

La lógica de `MapScene` añade encima:

- colisiones invisibles en edificios y límites;
- accesos a biblioteca, laboratorios y Coordinación;
- posiciones de personajes y objetos;
- rótulos breves para las ubicaciones relevantes;
- cámara de seguimiento sin deformar la imagen.

El archivo procede de los recursos gráficos aprobados del proyecto original y
se copió sin modificar sus dimensiones ni proporción.
