# Fondos de batalla

Recursos generados para diferenciar visualmente cada enfrentamiento de la
versión de demostración. No contienen personajes, texto, interfaz, logotipos ni
marcas de agua; Phaser superpone los combatientes y los controles.

## Biblioteca · Profie de Matemáticas

Archivo: `biblioteca-matematicas.png`

Prompt: fondo panorámico 16:9 en pixel art 2D pulido para una batalla
académica retro; biblioteca universitaria mexicana cálida, libreros de madera,
mesas y pizarrón con símbolos matemáticos abstractos; espacio libre para
jugador a la izquierda, enemigo a la derecha y panel inferior; sin personas,
zombis, texto legible, interfaz, logotipos ni marcas de agua.
